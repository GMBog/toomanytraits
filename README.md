This repository contains the IPython notebooks used to perform the analyses described in the manuscript by Cole (2025), "Are there too many traits in our
selection indices?" It also includes Excel (.xlsx) files containing Supplemental Tables 1-3. The input data are not included in this repository and they must be obtained from their original providers:
* The PTA for production, health, fitness, and calving traits used in this study may be downloaded from the Council on Dairy Cattle Breeding’s FTP site (ftp://ftp.uscdcb.com/) website.
* Genetic evaluations for conformation (type) traits may be requested from Dr. Jason Graham, Genetic Evaluation and Research Scientist, Holstein Association USA (jgraham _AT_ holstein.com).
