# toomanytraits — R Implementation

This repository contains R scripts adapted from the IPython notebooks 
originally developed by Cole (2025), "Are there too many traits in our 
selection indices?" The original Python implementation is available at 
[GMBog/toomanytraits](https://github.com/GMBog/toomanytraits).

This R adaptation was developed by Guillermo Martinez-Boggio (University 
of California, Davis) for use in the analyses described in:

XXXX

## Input Data

Input data are not included in this repository and must be obtained from 
their original providers:

- **Production, health, fitness, and calving trait PTAs** may be downloaded 
  from the Council on Dairy Cattle Breeding's FTP site: 
  ftp://ftp.uscdcb.com/
- **Genetic evaluations for conformation (type) traits** may be requested 
  from Dr. Jason Graham, Genetic Evaluation and Research Scientist, 
  Holstein Association USA (jgraham _AT_ holstein.com)
